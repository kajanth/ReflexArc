# Product Overview

NSA ReflexArc is a bio-inspired, config-driven AI organism that processes the physical world through a multi-layer neural cascade. It's designed as a complete digital nervous system that sees, hears, feels, learns, dreams, plans, and predicts.

## Core Concept

One config file = one brain. The system is 100% domain-agnostic and can be repurposed for any domain (DevOps, trading, IoT, customer support) by swapping the `config/brain.yaml` file.

## Neural Cascade Architecture

The system processes sensory input through a cost-optimized hierarchy:

- Layer 0: Peripheral Senses ($0) - Hardware detection via sensors
- Layer 1: RAS ($0) - Local embedding similarity filter for background noise
- Layer 2: Thalamus (~$0.001) - Cheap model triage routing
- Layer 3: Hippocampus ($0) - Vector memory storage/retrieval
- Layer 4: Cortex (~$0.01+) - Full reasoning (last resort)
- Layer 4.5: Template Engine (~$0.001) - Guided AI via markdown templates
- Layer 5: Cerebellum ($0) - Python skill execution (preferred outcome)
- Layer 5.5: Basal Ganglia ($0) - Habit reinforcement for faster routing

## Advanced Systems

- Digital Heart: Periodic health checks and circadian monitoring
- Dream Engine: Overnight memory consolidation, pattern discovery, auto-skill generation
- Prefrontal Cortex: Goal evaluation and proactive spike generation
- Predictive Cortex: Exponential smoothing forecasts with phantom spikes
- Broca's Area: Natural language interface for interrogation and modification

## Design Philosophy

Protocol Alpha (Conservation of Token Energy): Never use an expensive model for a cheap problem. Routing preference: REFLEX > TEMPLATE > LOG > COMPLEX.

The system operates in zero-token idle mode until a sensory spike is detected, then processes through the neural cascade to find the cheapest effective response.
